First time setup

Mac requires one quick Terminal command before Wild Sync can run. This only happens once.

xattr -cr "/Applications/Wild Sync.app"
  1. Open Terminal (Cmd + Space, type "Terminal")
  2. Paste the command above and press Enter
  3. Come back and click Continue
